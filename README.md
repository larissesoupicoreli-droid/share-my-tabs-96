# Shared Card Control

Uma melhoria que eu considero essencial: não faria o Matheus ter acesso simplesmente ao "cartão". Eu faria o sistema separar titular do cartão de responsável pela compra. Isso porque uma compra pode estar no cartão de uma pessoa, mas ser responsabilidade de outra — exatamente o tipo de situação que aparece nos seus controles atuais.

E eu acrescentaria uma tela que considero muito útil para vocês:

"Quanto cada um deve pagar na fatura?"

Assim, no fechamento do cartão, o sistema poderia mostrar:

Fatura Nubank — Agosto

 Larisse: R$ X

 Matheus: R$ X

 Mãe: R$ X

 Outros: R$ X

Total da fatura: R$ X

Isso transforma o sistema de uma simples "planilha de gastos" em um controle real das despesas compartilhadas dos cartões.
